# Example

```
npm ci
npm run dev
```

Open the page and upload one `.waosrec`. An empty local file is not
a dump. The file comes from `waosrec pack` in
[recorder-cpp](https://github.com/daemonarium/recorder-cpp).

Events is the frame timeline. Messages reassembles RPC on each
socket. API lists the type registries. Environment shows the socket
bindings from the dump.
